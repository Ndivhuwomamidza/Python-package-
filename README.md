Privacy Policy

PyPI Actions Studio · Last Updated: November 2026


1. Overview
PyPI Actions Studio ("we", "our", or "the app") respects your privacy. This application is a client-side developer utility designed to simulate GitHub Actions workflows, lint YAML configurations, and guide users through PyPI Trusted Publishing. We do not sell, rent, or monetize your personal data.

2. Information We Do NOT Collect
The application runs entirely within your browser or Android device:

No Account Required: You do not need to register, create an account, or log in.
No Credentials or Secrets Stored: We never request, capture, or store GitHub personal access tokens, PyPI API tokens, or passwords.
No Code or Workflow Tracking: Workflow YAML edits, package metadata, and logs are processed locally in temporary browser memory.
3. Device & Local Storage
The app may use local browser storage (such as localStorage or Service Worker caches) strictly to save your UI preferences, offline PWA assets, and unsaved YAML drafts. This information never leaves your device.

4. Third-Party Links & Services
The application contains links to external developer resources and platforms:

PyPI (Python Package Index): Links to official PyPI publishing guidelines and project pages.
GitHub: Links to GitHub repository management and Actions documentation.
PayPal: Voluntary donation links to support open-source development. All transactions are securely processed directly on PayPal's platform; we never see or handle your financial details.
